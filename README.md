# MY_Portfolio
This project is a fully responsive personal portfolio website built to showcase my skills, projects, writings, and professional journey as a Java Full-Stack Developer. The website is designed with a clean UI, smooth navigation, and user-friendly layouts to provide an engaging browsing experience for visitors, recruiters, and collaborators.

🚀 Features
🖥️ 1. Home & Navigation
    Modern and simple navigation bar
    Search option
    Category filter (All/Projects/Writing/etc.)
    Login and Sign-In pages included (UI only)

📂 2. Projects Section
     Highlights a variety of my academic and personal projects:

🔹 Smart Irrigation System

An IoT-based system that uses soil-moisture and weather sensors to automate irrigation, conserve water, and enhance crop yield.

🔹 Quiz Application

A full-stack web-based quiz platform built with:

Backend: Spring Boot

Frontend: React, HTML, CSS, JavaScript
It allows users to attempt quizzes, view scores, and enables admins to manage questions and quiz data.

🔹 Web Development Project

A digital resume/portfolio template built using HTML, CSS, and JavaScript focusing on UI, accessibility, and responsiveness.
